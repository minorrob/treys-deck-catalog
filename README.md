# Trey's Deck Catalog (mobile)

A phone-first view of Trey's Commander deck catalog: the 6 active decks, 33 designs grouped as in the master (Set 0, Set 1, Set 2, Group 0, Group 1, Crown Jewels, Hidden Gems), the bench, and the trading pages.

**Open it:** https://minorrob.github.io/treys-deck-catalog/

- Tap the deck name at the top to search and switch decks, or jump to a page.
- Each deck has three tabs: Overview, Cards and Stats. Tap any card for its details and the other designs that run it.
- **Sell:** the trade-in list with estimated store credit.
- **Buy:** Mechs (what to look for in the boxes, by mechanic and color, with example cards) and Singles (specific cards to pick up, including the Group 0 commanders).
- **Giveaway:** friends tick cards, set quantities and tap E-mail Asks to send the request.
- Cheat sheets: the D1 Tymna + Kraum play sheet, a mechanics glossary, and priority and the stack.

Direct links: `#D1` opens a deck (`#G0-D1.cards` its card list), `#SELL`, `#BUY`, `#GIVE`, `#BENCH`, `#PLAY-D1`, `#GLOSSARY`, `#STACK`.

The page is a single self-contained `index.html` (data and card images embedded). Prices are TCGplayer market via Scryfall (Oct 8, 2026; new pages and Group 0 Oct 11, 2026).
